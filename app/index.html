¿Podemos predecir el precio del petróleo con redes neuronales?

Estudio comparativo de RNN, LSTM y GRU para pronosticar el Brent a 5, 63 y 252 días bursátiles. Dos objetivos, una validación temporal y un referente exigente: el modelo ingenuo.

01 / El proyecto

El reto de pronosticar el Brent

Los mercados energéticos combinan tendencias, episodios de volatilidad y cambios inesperados. Evaluamos si las redes recurrentes pueden aprender patrones que mejoren una predicción sencilla: mantener el último precio observado.

01 · RNN

Red recurrente simple

Modelo base de secuencias, capaz de incorporar información histórica de manera recurrente.

02 · LSTM

Memoria a largo plazo

Incorpora compuertas para gestionar información temporal y posibles dependencias prolongadas.

03 · GRU

Memoria simplificada

Alternativa con compuertas y menos mecanismos que LSTM, diseñada para modelar secuencias.

02 / Metodología

Evaluación temporal, sin mezclar futuro y pasado

Usamos ventanas históricas de 60 sesiones, predicción de nivel o de retorno logarítmico y particiones cronológicas. El entrenamiento y la validación se realizan antes de evaluar el bloque final de test.

01 Datos históricos del Brent y variables de mercado02 Ventana de 60 sesiones03 RNN · LSTM · GRU04 Walk-Forward de 5 folds05 Test final

NIVEL

La red predice directamente el precio futuro del Brent en USD/barril.

RETORNO

La red predice el retorno logarítmico y reconstruimos el precio futuro para compararlo en la misma escala.

INGENUO

El precio futuro pronosticado es el último precio observado. Es la referencia frente a la que calculamos el Skill.

04 / Conclusiones

La complejidad no garantiza mejores predicciones

En esta evaluación, el modelo ingenuo alcanza el menor MAE en los tres horizontes. Las redes neuronales muestran comportamientos diferentes según el plazo y la variable objetivo.

Redes neuronales más competitivas

En el análisis original, la RNN de retorno presenta el menor MAE entre las redes a 5 y 63 días; a 252 días destaca la RNN de nivel. Estas preferencias son descriptivas del test, no una selección previa mediante validación.
