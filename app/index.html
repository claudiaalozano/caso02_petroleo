04 / RISK & CONFIDENCE

La incertidumbre también es información.

Una predicción puntual no representa todos los futuros posibles. La volatilidad, los errores históricos y el horizonte temporal condicionan la amplitud del intervalo.

¿Qué significa un intervalo del 80 %?

Es un rango de predicción nominal construido con nuestro método de incertidumbre. No implica que exista una garantía del 80 % para cada caso individual: su cobertura debe evaluarse en datos no utilizados para calibrarlo.

80 % nominal·La cobertura real puede variar por régimen de mercado

Cómo interpretamos el Skill

Skill = 1 − MAE(modelo) / MAE(ingenuo). Un valor positivo favorece al modelo; negativo significa que el ingenuo fue mejor.

Skill positivoMejora sobre referencia
Skill ceroEmpate con ingenuo
Skill negativoRendimiento inferior
05 / RESEARCH FRAMEWORK

Ciencia detrás del diseño.

Un sistema completo de pronóstico exige trazabilidad, particiones temporales correctas y comparación con un referente sencillo.

01 / INPUT

Información de mercado

El proyecto utiliza variables históricas del Brent y señales externas. Las ventanas de entrada contienen 60 sesiones y el preprocesamiento evita adelantar información futura.

02 / LEARNING

Tres redes recurrentes

RNN, LSTM y GRU entrenadas con pérdida Huber, selección temporal de épocas y semillas múltiples. Se comparan objetivos de nivel y retorno.

03 / EVALUATION

Walk-Forward y test

Validación cronológica con cinco folds y un periodo final de test. Reportamos MAE, sesgo, dirección, Skill e incertidumbre sin confundir validación con producción.
